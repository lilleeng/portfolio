MNIST object detection

Tegn på lerretet og en maskinlærings modell vil utføre object detection for å predikere hvilket siffer er tegnet (klassifisering) og hvor i bildet sifret er tegnet. En rød bounding box vil bli tegnet rundt sifret for å vise modellens prediksjon. Man kan tegne flere sifre.

    Om prosjektet (i stikkordsform)

    Fra universitetet. Datasettet innholdt da bare sifrene 0 og 1 med støy lagt i bakgrunn av alle bildene. Ville gjøre likt som 'MNIST med lerret' prosjektet. Mye gjenbrukt kode fra prosjektet gjort på universitetet. Datasettet måtte skaffes på nytt.

    Datasettets opphav

    Etter et kjapt søk fant jeg ikke noe datasett jeg kunne bruke for dette prosjektet. Skjønte jeg kunne gjenbruke MNIST datasettet og få til mye mer. I MNIST datasettet er alle bildene 28x28 piksler stort. Jeg lagde kode for å kunne lage hvilken som helst størrelse bilder, uten støy, med variabelt antall sifre i bildene. -> mye større datasett enn hva jeg kunne lastet ned fra internett. Alt lages og lagres i minne så tar ingen plass. Kontrollering av random seed lar meg reprodusere datasettet.

    Om modellen(e)

    Modellen som brukes nå (CNN) har omtrent akkurat samme arkitektur som det jeg brukte i prosjektet på universitetet. Liten endring bare for å tilpasse endret input størrelse. Overrasket over at det ikke trengtes å justere modellen mer for å få fornøyelig resultat.
